# Destellos de Gracia Radio

Página estática para GitHub Pages. Publicar desde la raíz de la rama main, mediante Settings → Pages → Deploy from a branch.

Prédicas desde sus enlaces públicos existentes; identificaciones de Liora, piano y piloto histórico incluidos. Cada oyente reproduce una secuencia independiente. No es una señal en vivo sincronizada.

El piloto de Panorama corresponde al 28 de octubre de 2026 y no representa noticias actuales. ediciones.json está vacío: todavía no existe una producción y publicación automática de reportes diarios.

No requiere claves, servicios de IA ni funciones de servidor para escuchar. Consultas de nuevos reportes cada cinco minutos. Mantener los originales fuera de este repositorio.
